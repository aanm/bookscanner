# Contributing
This is a personal project. Contributions are **not** being accepted.
Please don't open pull requests. Issues for clear bug reports are fine,
but there's no guarantee they will be looked at or acted on.
If you'd like to build on this code, your best option is to fork it.
The project is released under the [Apache License 2.0](./LICENSE), so
you're free to do so.

Interactions in this project are subject to the
[Code of Conduct](./CODE_OF_CONDUCT.md).

**Do not report security issues in public issues.** See
[SECURITY.md](./SECURITY.md) instead.
