# Security Policy

This document outlines security procedures and general policies for the
`bookscanner` project.

## Disclosing a security issue

Security issues in `bookscanner` are taken seriously. Thank you for improving
the security of the project and for your dedication to responsible disclosure.

`bookscanner` leverages GitHub's private vulnerability reporting. To learn more
about this feature and how to submit a vulnerability report, review
[GitHub's documentation on private reporting](https://docs.github.com/code-security/security-advisories/guidance-on-reporting-and-writing-information-about-vulnerabilities/privately-reporting-a-security-vulnerability).

Please **do not** report security vulnerabilities through public GitHub issues.

Helpful details to include in your report:

- a detailed description of the issue
- the steps required to reproduce the issue
- versions of the project that may be affected by the issue
- if known, any mitigations for the issue

You will receive an acknowledgement of your report, and further updates as the
issue is investigated and resolved.
